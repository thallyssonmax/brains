# Brains

Flashcards com revisão espaçada. Aplicação React + TypeScript em `app/`.

Node.js 24: `cd app`, `npm ci`, `npm test`, `npm run build`.

Vercel: Root Directory `app`, framework Vite. Configure `VITE_SUPABASE_URL` e `VITE_SUPABASE_PUBLISHABLE_KEY` no projeto. Nunca use chaves secretas no frontend.
