# UX decisions — 16 September 2026
Use context before alerts: review availability is inline metadata beside the action.
Info: pending attachment transfer only. Warning: failed/retryable attachment cleanup or changed recorded text. Error: action failed, keep recovery action. Success: existing brief save confirmation.
Do not add banners for ordinary navigation, automatic saving or an empty review queue.
Mobile: minimum 44px close target, stack actions below 380px, respect reduced motion, preserve focus after dialogs and announce selected navigation/filters.
Drafts are persisted only after changes; existing drafts remain.
Texts updated in Portuguese, English and Spanish. Timezones remain stored as IANA identifiers, presented as city/region selection. Dates use the account timezone without seconds.
Remaining device validation: VoiceOver, iOS virtual keyboard and actual zoom. Optional image descriptions require a separate data-model change and are not included here.
